# Estatein

A modern real estate landing page built from a Figma design, converted to production-ready HTML with **v0 by Vercel**, enhanced with **Tailwind CSS**, and deployed to a **VPS** using a fully automated **GitHub Actions CI/CD workflow**.

**🌐 Live Demo:** https://estatein.wellington.codes

---

## ✨ Overview

Estatein is a demonstration project showcasing a modern frontend development workflow—from design to deployment.

The project highlights how a UI design can be transformed into a responsive website using AI-assisted development tools while maintaining a streamlined deployment pipeline.

---

## 🚀 Tech Stack

* **Figma** — UI/UX Design
* **v0 by Vercel** — Design-to-HTML generation
* **HTML5**
* **Tailwind CSS** — Styling and responsive layouts
* **GitHub Actions** — Continuous Integration & Continuous Deployment
* **VPS** — Production hosting

## 🔄 Deployment

Every push to the deployment branch automatically triggers the GitHub Actions workflow.

The workflow:

1. Checks out the repository
2. Builds/prepares the project
3. Connects securely to the VPS
4. Deploys the latest version
5. Publishes the updated website

This provides a simple and reliable CI/CD pipeline with minimal manual intervention.

---

## 🎨 Design Process

The interface was originally designed in **Figma**.

The design was then converted into HTML using **v0 by Vercel**, after which the generated markup was refined and integrated with **Tailwind CSS** to improve responsiveness, maintainability, and styling consistency.
